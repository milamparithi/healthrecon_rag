# HealthRecon Rag Project

## Spec

- Keep Architecture, Implementation Plan, Test Plan files under 'spec' folder and keep it up to date whenever you make
any changes.

## Architecture style

- Do not over engineer
- Use software engineering best practices
- Do not hesitate to refactor if it will increase the code quality

- The app must be a mobile responsive Single Page Application.
- The app must be dockerized
- Proper unit tests must be generated for all layers
- The UI should be intuitive, user-friendly and minialistic with light theme.
- use best practices in the folder structure for both the front-end and back-end. (like api, models, services, components, pages etc)
